A page with no semantic tags at all

There is no article tag here, no main, and no schema markup, which is the state of most of the web outside of publishing platforms. The only way to find the content is to score the containers and take the best one.

This paragraph exists so that the content div carries more text than the navigation blocks do, because that is exactly the comparison the scorer makes when it has nothing else to go on.

A third paragraph, because paragraph count is part of the score and a boilerplate block almost never has three real ones.
