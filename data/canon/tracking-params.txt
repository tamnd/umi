# Tracking and session parameters removed by step 10 of URL canonicalisation.
#
# This file is the list. It is compiled into the binary with include_str! and
# it is published to open-index/umi-meta alongside every dataset, so anyone
# who wants to reproduce a umi url key can, without reading our source. That
# is the whole reason it is a file: a constant in a Rust source tree is not
# something a Python user reproducing our keys can reach.
#
# Adding a line here changes every key derived from a URL carrying that
# parameter, so it is a canonicalisation version bump and not a patch. See
# docs/spec/11-extraction-and-dedup.md section 11.2.
#
# Syntax, one rule per line:
#   name        remove this parameter whenever it appears
#   prefix*     remove any parameter whose name starts with prefix
#   name?       remove only when the value looks like a session token
# Comparison is case insensitive. Blank lines and # comments are ignored.

# Session identifiers. These are the dangerous half of the list, because a
# session parameter left in place turns one page into unbounded URLs, and a
# content parameter removed by mistake merges two pages and silently loses
# one. Anything ambiguous gets the `?` suffix and is judged by its value.
sessionid
